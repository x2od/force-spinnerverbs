# force-spinnerverbs

Custom spinner verbs for Salesforce-flavored loading messages. The verbs live in [`forceSpinning.json`](forceSpinning.json).

Want to add or change a verb? Read [CONTRIBUTING.md](CONTRIBUTING.md) for the rules, then open a pull request. Have a feature idea or a complaint? Open an issue using one of the templates.
