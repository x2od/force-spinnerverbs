# force-spinnerverbs

Custom spinner verbs for Salesforce-flavored loading messages. The verbs live in [`forceSpinning.json`](forceSpinning.json).

## Contributing a verb

1. Fork the repo and edit `forceSpinning.json`.
2. Follow the rules:
   - Multi-word verbs are hyphenated, with no spaces: `Data-loader-exporting`.
   - Every verb ends in `ing`.
   - Keep the first four lines and last three lines of the file unchanged.
3. Open a pull request. The **Validate spinner verbs** check must pass before a PR can merge.

Have a feature idea or a complaint about a verb? Open an issue using one of the templates.
